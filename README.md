# Digital 박 터뜨리기

센서와 Vision을 결합한 체험형 경기 시스템입니다. 타격을 감지하고 위치와 충격량을 점수에 반영하는 방식으로 개발했습니다.

## 본인 역할

3인 팀 프로젝트에서 센서와 Vision을 활용한 판정 구조를 개발하고 현장 운영과 오류 대응을 수행했습니다.

## 시스템 구성

| 구성 | 역할 |
| --- | --- |
| NUC126 / ARM Cortex-M0 MCU | GPIO 인터럽트로 충격 감지, 게임 상태와 점수 관리, 출력 장치 제어 |
| Raspberry Pi 5와 카메라 | 영상 입력, AI 추론, 타격 지점 검출 |
| 400MHz RF 모듈 | MCU와 Raspberry Pi 간 판정 요청 및 결과 송수신 |
| 24×24 NeoPixel | 타격 위치와 게임 상태 표시 |
| 모터, 펌프, 음향 장치 | 판정 결과에 따른 물리적 피드백 |

실시간 입출력은 MCU가, 영상 분석은 Raspberry Pi가 담당하도록 분리했습니다. RF 모듈은 UART 9600 bps로 연결하고, 메시지를 Command, Address, Data로 나눠 요청 종류와 대상 장치, 좌표 및 판정 결과를 전달했습니다.

## 설계와 문제 해결

24×24 영역에 센서를 각각 붙이는 방식 대신 충격 센서로 타격 시점을 감지하고 카메라로 위치를 판단했습니다. 충격 전후 프레임을 비교하고 YOLO로 새롭게 나타난 콩주머니의 위치를 확인했습니다. 검출 지점은 LED 격자 좌표로 변환해 점수와 출력 장치에 반영했습니다.

타격 누락이 반복될 때 센서 민감도뿐 아니라 충격 전달 구조를 점검했습니다. 하부 지지 부품의 위치와 재질을 조정한 뒤 반복 타격으로 동작을 확인했습니다.

## 현장 대응

행사에서는 많은 학생이 연속해서 이용했습니다. 촬영과 분석에 필요한 대기를 줄이기 위해 카메라 기반 위치 판정을 제외하고 충격 감지 중심으로 운영했습니다.
