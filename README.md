# Digital 박 터뜨리기

센서와 Vision을 결합한 체험형 경기 시스템입니다. 타격을 감지하고 위치와 충격량을 점수에 반영하는 방식으로 개발했습니다.

## 본인 역할

3인 팀 프로젝트에서 센서와 Vision을 활용한 판정 구조를 개발하고 현장 운영과 오류 대응을 수행했습니다.

## 설계와 문제 해결

24×24 영역에 센서를 각각 붙이는 방식 대신 충격 센서로 타격 시점을 감지하고 카메라로 위치를 판단했습니다. 충격 전후 프레임을 비교하고 YOLO로 새롭게 나타난 콩주머니의 위치를 확인했습니다.

타격 누락이 반복될 때 센서 민감도뿐 아니라 충격 전달 구조를 점검했습니다. 하부 지지 부품의 위치와 재질을 조정한 뒤 반복 타격으로 동작을 확인했습니다.

## 현장 대응

행사에서는 많은 학생이 연속해서 이용했습니다. 촬영과 분석에 필요한 대기를 줄이기 위해 카메라 기반 위치 판정을 제외하고 충격 감지 중심으로 운영했습니다.

개발 버전의 위치 판정과 행사 운영 버전의 기능 범위가 다릅니다.

## 공개 범위

현재는 프로젝트 설명 문서입니다. 실행 코드와 시험 기록은 포함하지 않았습니다. 장치 사진, 버전별 시연과 개인 담당 코드는 정리 후 추가할 예정입니다.
